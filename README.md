# 🎓 University Management System (UMS) App

The UMS App is an all-in-one Android application designed to simplify university operations for students, faculty, and administration. This app provides seamless access to academic records, schedules, notifications, and more, ensuring a smooth university experience.

## 🚀 Features

- 📚 **Student Portal**: Access academic records, grades, and attendance.
- 📆 **Timetable Management**: View daily, weekly, or semester schedules.
- 📝 **Assignments & Exams**: Submit assignments and check exam schedules.
- 🔔 **Notifications**: Receive important updates, announcements, and deadlines.
- 💬 **Faculty Communication**: Directly contact professors or faculty members.
- 🧑‍🎓 **User Profiles**: Manage student, faculty, or admin profiles efficiently.
- 🏫 **Campus News**: Stay updated with campus events and news.
- 📱 **Responsive Design**: Optimized for various Android devices and screen sizes.

## 📦 Installation

Follow these steps to get started with the UMS App:

1. **Clone the repository**:
   https://github.com/huzaifaAhmad9/UMS.git

2. **Open the project**: Open the project folder in Android Studio.

3. **Sync Gradle**: Allow Android Studio to sync Gradle dependencies automatically.

4. **Build the project**: Click on Build > Make Project to ensure there are no build errors.

5. **Run the app**: Connect an Android device or emulator and click on Run.


## 🛠 Built With

- Java: Core programming language for building the app.
- Android SDK: Android libraries and tools for development.
- SQLite: Local database for storing user data and cart items.
- Retrofit: For seamless API integration.
- Glide: For efficient image loading.
- Firebase: Used for notifications and analytics.
